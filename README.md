BhashaSetu

AI-Powered Vernacular Pedagogy & Real-Time Translation for Tribal Primary Classrooms

Smart India Hackathon 2026 — Problem Statement ID: SIH26042

BhashaSetu is an education platform designed to support mother-tongue-based primary education in tribal and multilingual classrooms.

It connects teachers, students and education officials through multilingual learning, translation, voice interaction, classroom activities and progress monitoring.

🎯 Problem

Many primary-school students learn better in their mother tongue, but teachers may not have sufficient multilingual teaching resources or tools for real-time translation.

BhashaSetu aims to reduce this language barrier by connecting curriculum content with vernacular learning.

💡 Proposed Solution

BhashaSetu provides a single platform for:

- Mother-tongue learning
- Multilingual lesson translation
- AI-powered explanations
- Voice-based interaction
- Teacher-created lessons
- Worksheets and quizzes
- Student learning and progress tracking
- Educational content scanning
- Offline-first classroom support
- Official curriculum/content review

👩‍🏫 Teacher Features

- Teacher dashboard
- Create and translate lessons
- Upload PDF, DOC, image and audio content
- Generate worksheets
- Create assignments and quizzes
- Assign learning content to students
- Classroom learning sessions
- Monitor student progress
- Multilingual classroom resources

🎒 Student Features

- View assigned lessons
- Complete worksheets
- Attempt quizzes
- Access bilingual learning material
- Track learning progress
- Download learning resources
- Ask the AI learning assistant questions
- Use translation and voice-learning tools

🌐 AI & Language Features

- AI Translator & Explainer
- Text and document translation
- Child-friendly explanations
- Bilingual learning
- Voice conversation
- Speech-to-text interaction
- Textbook/image scanning
- Educational visual learning
- AI-assisted question answering

Supported prototype languages include:

- Ho
- Mundari

- Hindi
- English

📴 Offline-First Learning

BhashaSetu is designed for environments with limited or unreliable internet connectivity.

The prototype uses browser-based local storage/IndexedDB to support offline classroom functionality and local data persistence.

🔐 Security & Privacy

The production version should use:

- Role-based access control
- Secure authentication
- Supabase Row Level Security
- Protected student information
- Secure API keys and environment variables
- Minimum collection of personal data

Never commit API keys, passwords, Supabase service-role keys or other secrets to the repository.
